真实实验数据格式与统计口径

每条记录表示一个样本的一次轮末独立评估。epoch = 0 表示训练前；epoch = t 的 update_count 对应该轮训练期间产生有效奖励信号的 rollout 组数。每题每轮只有一组时，填 0 或 1 即可。

sample_0001,2,40,256,1

sample_0002,2,69,256,1
字段含义
sample_id稳定且唯一的样本 ID；跨轮次不能更换 ID
epoch非负整数；所有样本必须有 epoch=0 的初始评估
eval_correct / eval_total独立评估的正确数 / 总采样数；不是训练 rollout 的正确数
update_count该轮有效奖励组数，非负整数；初始列填 0

JSON 可为记录数组，或 {"expected_samples":1000,"records":[...]}；JSONL 每行一个记录对象。可一次导入多份文件，合并时重复的 (sample_id, epoch) 会报错。expected_samples 可选，用于校验实际样本数；不提供时自动识别。

初始档位为 0%、(0%,5%]、(5%,10%]、…、(95%,100%]；只按初始评估分组并排序，后续不重新排序。缺少轮次记录会显示斜纹，不会被当作零成功率或“未采样”。导入错误时保留此前已载入的数据。

有效奖励组数需要训练端记录。对只有二元奖励的标准组内相对优势 GRPO，有对有错的一组通常有奖励学习信号，全错或全对的一组通常没有。这里不代表整个 optimizer step 是否发生，也不包含 KL、熵、动量等影响。页面不会通过评估成功率推断训练更新。

同一轮比较请固定评估 prompt、温度、输出长度和判分器，并使用独立评估采样。pass@k 使用无偏组合估计 1 − C(n−c,k)/C(n,k)，要求 k≤n；零命中不等于真实成功率为零。跨样本或跨轮次的统计显著性需要另行分析。

本页无外部脚本、字体或网络请求，直接打开 index.html 即可。浏览器刷新后重新导入数据。长图 SVG 导出当前筛选的全部样本与轮次，PNG 只导出当前可见区域。
